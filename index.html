route-log.log

Route Log — Work Day Tracker

✅ status: live

$ ./run route_log.js

A single-page, calendar-based travel/work-log app with a custom-styled UI — no external frameworks. Each date can hold multiple travel legs (from, to, distance), with distance calculated using the Haversine formula and everything persisted to localStorage. A "Jump to Date" control with dynamic day/month/year dropdowns makes it quick to reach any date, and running totals — distance and days worked — update automatically for both the selected day and the current month.
