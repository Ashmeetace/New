School Management System

Live

A student and staff records system built to demonstrate a properly structured, relational database rather than a flat-file prototype. The backend is written in Python and connects to a MySQL database, with the schema split across three related tables — students, teachers, and feedback — keeping the data consistent rather than duplicated.

The application is split into separate Admin and User views: administrators get full create, read, update, and delete access, including a quick field-picker for updating a single detail without resubmitting the whole record, while regular users get read-only, search-friendly views. Every query is built to be safe against malicious input.

Route Log — Work Day Tracker

Live

A single-page, calendar-based travel and work-log app, built with plain HTML, CSS, and JavaScript. It tracks multiple work trips per day, each with its own origin, destination, and distance, in a way that's faster to log than a spreadsheet.

Distance is calculated automatically rather than entered by hand, and everything is saved right in the browser. A "Jump to Date" control makes it fast to reach any date directly, and running totals update automatically for both the day and the month.
